# Modulo booleans

booleans nos permite usar booleanos(falsos por supuesto) para que el codigo dea mas legible y se entienda mejor, tiene estas funciones:7

* isbool
* bool

y estas variables

* True
* False

## isbool

Recibe un unico argumento, si ese argumento es True o False retorna 1, si no 0

## bool

Recibe un unico argumento y evalua si es un valor verdadero por ejemplo 1 o "hola" retorna 1, si no 0

## True y False

Son variables numericas

True = 1
False = 0
