# Relacionados con archivos

## open

`open` recibe dos argumentos obligatorios y uno opcional, el primer argumento es la ruta del archivo a abrir, el segundo es el modo y el tercero el texto a escribir en caso de que el modo sea de escritura.

Si el modo es "r" la funcion retornara el texto del contenido del archivo en ignorara el argumento de contenido de escritura.
Si el modo es "w" la funcion escribira el tercer argumento dentro del archivo
Si el modo es "w+" la funcion añadira el tercer argumento al archivo
